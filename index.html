The 8-Puzzle

Eight numbered tiles sit on a 3 by 3 board with one empty square. A move slides a neighbouring tile into the empty square. The task is to reach a chosen goal arrangement from a chosen start arrangement.

As a search problem, each arrangement is a state, each slide is an action, and each action has a cost. Of the 9! = 362,880 arrangements, exactly half can reach any given goal, so the app checks solvability before searching.

Uniform Cost Search always expands the frontier node with the lowest path cost g(n). It is complete and optimal. With a cost of 1 per move it finds the shortest solution. Switch the move cost to "tile number" to see it choose cheaper moves instead of fewer moves.
